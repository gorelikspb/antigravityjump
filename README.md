# Anti-Gravity Jump

A fast-paced 2D puzzle-platformer built with **Godot 4.7** where you flip gravity in **all 4 directions** (`UP`, `DOWN`, `LEFT`, `RIGHT`) and must collect every **Rhombus Crystal (`◆`)** in each room to unlock the exit.

### 🎮 Play Online in Browser
👉 **[Play Anti-Gravity Jump on GitHub Pages](https://gorelikspb.github.io/antigravityjump/)**

---

### Controls
- **Move:** `WASD` / Left Stick
- **Jump:** `Space` / `K` / Gamepad `A`
- **Flip Gravity:** `Arrow Keys (↑ ↓ ← →)` / `D-Pad`
- **Restart Room:** `R`
- **Main Menu:** `Esc`
