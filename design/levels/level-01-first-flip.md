# Level 01 — "First Flip" (test / tutorial)

> **Owner:** level-designer · **Status:** Greybox · **Scene:** `src/levels/level_01.tscn` · **Date:** 2026-11-07

## Purpose

Обучить трём действиям и **всем 4 направлениям** гравитации за ~60 секунд.
Grid = 32 px. Размер уровня 2064 × 720 (потолок y=0..80, пол y=640..720).

## Layout (top view, x →)

```
x:   0        400  480     800        1120 1200   1600 1664   1760          2000 2064
     ┌────────────────────────────────────────────────────────────────────────────┐ ceiling
     │                                               │      ^^^^^^^^^^^^^^^^^^^^^^│ <- ceiling spikes (x1700..2000)
     │                                               │ L                     GOAL │
     │                                               │ wall      ═══════ledge═════│ R wall
     │  S        ┌──┐            [Zone↓]  C          │(80..576)                   │
     │           │st│            │      │            ▼ gap 64px                   │
     └───────────┴──┴────┐vvvvvv┌┴──────┴────────────────────────────────────────┘ floor
                         └spikes┘ (pit)
```

## Beats

| # | Section | x-range | Учит | Решение |
|---|---------|---------|------|---------|
| 1 | Start | 0–800 | бег, прыжок | Ступень 64 px (x 400–480) — запрыгнуть. |
| 2 | The Pit | 800–1120 | **флип ВВЕРХ** | Яма 320 px с шипами не перепрыгивается (дальность ~158 px). Флип ↑, бег по потолку. |
| 3 | Safety Zone | 1120–1200 | Gravity Zone | Зона ↓ возвращает на пол, если игрок забыл флипнуть. Checkpoint на x=1260. |
| 4 | The Chamber | 1600–2064 | **флип ВЛЕВО, ВПРАВО, ВНИЗ**, воздушный флип | Под потолком шипы → путь «по потолку» закрыт. Вход под левой стеной (зазор 64 px). Решение: прыжок + воздушный флип ← → «пол» = правая грань левой стены → идти вверх (W) выше уступа → флип → → долететь до финиша над уступом (или до правой стены и флип ↓ на уступ). |

## Ловушки-«учителя»

- Флип ↑ под уступом → упираешься в низ уступа; сход с него → ceiling spikes. Учит «смотреть, куда упадёшь».
- Флип → с пола в Chamber → упираешься в низ уступа (ledge перекрывает путь по правой стене).

## Metrics

- Целевое время: эксперт 20 s, новичок 60–120 s. Ожидаемые смерти новичка: 2–6.

## Acceptance Criteria

- [ ] Уровень проходим только с использованием всех 4 направлений (кроме читерских путей, найденных QA → баги).
- [ ] Нет мест, где игрок может застрять без возможности умереть/рестарта (R всегда доступен).
