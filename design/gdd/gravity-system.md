# Gravity System

> **Owner:** game-designer · **Reviewed by:** technical-director · **Status:** Approved (prototype) · **Date:** 2026-11-07

## Summary

Гравитация действует на игрока в одном из 4 дискретных направлений. Игрок меняет её
вручную (стрелки / D-pad), уровень — через Gravity Zones. На земле переключение
бесконечно, в воздухе — ограничено «воздушными зарядами».

## Overview

Гравитация — локальное свойство **игрока** (не глобальный `PhysicsServer` default),
поэтому другие объекты мира не затронуты, а уровни детерминированы.

## Player Fantasy

«Я переписываю правила комнаты»: потолок становится дорогой, стена — лифтом.

## Detailed Design

### Core Rules

1. `GravityDir ∈ {DOWN, UP, LEFT, RIGHT}`; стартовое направление задаётся уровнем (по умолчанию DOWN).
2. Ввод `gravity_<dir>` устанавливает **абсолютное (экранное)** направление, а не поворот относительно текущего. Причина: предсказуемость (P3).
3. Повторный ввод текущего направления — игнорируется (заряд не тратится).
4. На земле (`is_on_floor()` относительно текущего «верха») смена бесплатна.
5. В воздухе смена тратит 1 воздушный заряд. При 0 зарядах ввод игнорируется + звуковой/визуальный «отказ».
6. Заряды полностью восстанавливаются при приземлении на любую поверхность.
7. При смене гравитации мировая скорость **сохраняется**, но компонента вдоль новой гравитации обнуляется, если она направлена «против» неё сильнее `flip_carry_limit` (защита от «катапульты»).
8. Gravity Zone принудительно ставит направление, **не тратит заряд** и восстанавливает заряды.

### States and Transitions

| State | Вход | Выход |
|-------|------|-------|
| `GROUNDED` | касание пола (относительно гравитации) | прыжок / сход с края / смена гравитации |
| `AIRBORNE(charges=n)` | отрыв от пола | приземление → `GROUNDED`, смена → `AIRBORNE(n-1)` |
| `DEAD` | шипы / вылет за границы | респаун → `GROUNDED` с гравитацией чекпоинта |

### Interactions with Other Systems

- **Player Movement:** задаёт `up_direction = -gravity` и ось движения (касательную).
- **Gravity Zones / Checkpoints:** вызывают `Player.set_gravity(dir, forced=true)` / сохраняют направление.
- **HUD:** подписан на `gravity_changed(dir)` и `air_charges_changed(n)`.

## Formulas

- `g_vec = to_vector(dir) * gravity_strength`
- `tangent = g_vec.normalized().rotated(-PI/2)` (направление «вправо» для игрока; используется только для вращения визуала)
- Скорость вдоль гравитации: `v_n = velocity.dot(g_dir)`; за кадр: `v_n = min(v_n + gravity_strength * Δt, max_fall_speed)`
- Высота прыжка: `h = jump_velocity² / (2 · gravity_strength)`. При 480 / 1400 → **≈ 82 px** (2.5 тайла по 32 px).
- Время в воздухе (на ровном): `t = 2 · jump_velocity / gravity_strength` → **≈ 0.69 s**.

## Edge Cases

- **Смена гравитации в углу (пол + стена):** персонаж просто «падает» на стену, если её грань ближе; если касается обеих — сразу `GROUNDED` на новой поверхности, заряд не тратится (он на земле в момент нажатия).
- **Смена в Gravity Zone на другое направление:** ручной ввод разрешён, зона повторно применяется только при новом входе.
- **Две перекрывающиеся зоны:** побеждает последняя вошедшая.
- **Смена гравитации в тот же кадр, что и прыжок:** сначала прыжок (по старой гравитации), затем смена.
- **Ввод во время `DEAD`:** игнорируется.

## Dependencies

- Player Movement (двусторонне: movement читает `gravity_dir`, gravity читает `is_on_floor`).
- Level Flow (чекпоинты хранят направление).

## Tuning Knobs

| Knob | Default | Safe range | Влияет на |
|------|---------|------------|-----------|
| `gravity_strength` | 1400 px/s² | 900–2200 | «вес», высота прыжка |
| `max_fall_speed` | 720 px/s | 400–1200 | контроль при длинном падении |
| `air_flip_charges` | 1 | 0–3 | сложность / свобода решений |
| `flip_carry_limit` | 240 px/s | 0–600 | сохранение импульса при флипе |
| `rotate_visual_speed` | 18 rad/s | 8–40 | читаемость поворота спрайта |
| `camera_follows_gravity` | false | bool | укачивание vs. погружение |

Все значения — в `assets/data/player_config.tres` (класс `PlayerConfig`).

## Visual/Audio Requirements

- Визуал игрока плавно поворачивается «ногами» к гравитации.
- HUD-стрелка направления; индикатор зарядов (точки).
- (Sprint 2) SFX: флип, отказ флипа, приземление.

## Game Feel

Флип должен ощущаться **мгновенным**: новая гравитация применяется в тот же физический кадр.
