# Level Flow, Hazards & Gravity Zones, HUD

> **Owner:** game-designer + level-designer · **Status:** Approved (prototype) · **Date:** 2026-11-07

## Summary

Правила прохождения уровня: старт → чекпоинты → финиш; смерть = мгновенный респаун.

## Detailed Design

### Core Rules (прохождение уровня)

1. Уровень стартует со `Spawn` и стартовым направлением гравитации.
2. **Цель:** коснуться `Goal`. Тогда уровень завершён: показ времени и числа смертей.
3. **Смерть:** касание `Spikes` или выход за `level_bounds`. Счётчик смертей +1, респаун на последнем чекпоинте (или Spawn) с его гравитацией и нулевой скоростью.
4. **Checkpoint:** активируется касанием, запоминает позицию и **текущую гравитацию** игрока. Повторно не активируется назад.
5. Таймер идёт с первого кадра уровня до касания Goal; смерти таймер не сбрасывают.
6. `R` — полный рестарт уровня (таймер и смерти сбрасываются).
7. На экране итогов: `Enter` — следующий уровень (если задан), `R` — заново.

### Hazards & Gravity Zones

| Объект | Поведение |
|--------|-----------|
| `Spikes` | Area2D, мгновенная смерть при касании, ориентация любая. |
| `GravityZone` | Area2D, при входе ставит гравитацию `forced` (без траты заряда, восстанавливает заряды). Визуально — полупрозрачная полоса со стрелками. |
| `Checkpoint` | Флажок, меняет цвет при активации. |
| `Goal` | Финишная зона. |
| `Block` | Статичная геометрия (greybox), любой размер. |
| `RechargeCrystal` | Area2D (RectTrigger). При касании вызывает `player.refill_air_charges()`. Если заряд игрока был `< max` (или при `always_consume = true`), кристалл пополняет заряд, уходит в кулдаун на `respawn_time` (по умолчанию `2.5` с), становится полупрозрачным/контурным и проигрывает звук `CHECKPOINT` с повышенным питчем (`1.3`). При рестарте уровня активен сразу. |

## Edge Cases

- Касание Goal и Spikes в один кадр → **победа** (щедрость).
- Смерть во время экрана итогов невозможна: игрок замораживается.
- Чекпоинт внутри Gravity Zone: респаун применяет гравитацию чекпоинта, зона переприменяется при следующем входе.

## UI Requirements

HUD (CanvasLayer), только подписка на сигналы `Level`/`Player`, без обратных ссылок:
- Таймер `mm:ss.cc` (верх-лево), смерти (верх-лево, под таймером).
- Стрелка гравитации + точки воздушных зарядов (верх-право).
- Панель «LEVEL COMPLETE»: время, смерти, подсказки клавиш.
- Подсказка управления внизу экрана (скрываема в Sprint 2).

## Acceptance Criteria

- [ ] AC-L1: Шипы убивают, респаун < 0.5 s, счётчик смертей +1.
- [ ] AC-L2: После чекпоинта респаун происходит на нём, с сохранённой гравитацией.
- [ ] AC-L3: Goal останавливает таймер и показывает панель итогов.
- [ ] AC-L4: `R` сбрасывает таймер и смерти.
- [ ] AC-L5: Падение за пределы уровня = смерть.
